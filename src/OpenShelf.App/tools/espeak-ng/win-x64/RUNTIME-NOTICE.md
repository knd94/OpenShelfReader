# eSpeak NG runtime

This directory contains the official eSpeak NG 1.52.0 Windows x64 runtime and
voice data, redistributed under GPL-3.0-or-later.

- Project: <https://github.com/espeak-ng/espeak-ng>
- Release: <https://github.com/espeak-ng/espeak-ng/releases/tag/1.52.0>
- Installer SHA-256:
  `7F673C709EA5DD579D3B5EBB98688CC575328A6AB7438D2BC405B88CEDAEAFB9`

The complete corresponding source is bundled at
`source/espeak-ng-1.52.0-source.zip` (SHA-256
`B4517592E3CBC43703BB1C782702EAFB98097659E0B7E96E69C32EE32AE5003A`) and is
also available from the project release page. OpenShelf invokes
`espeak-ng.exe` directly with shell execution disabled and supplies text over
standard input.
