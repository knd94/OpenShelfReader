# libmobi 0.12

`libmobi.dll` is dynamically loaded by OpenShelf for DRM-free MOBI and AZW3
decompression. It was compiled from the unmodified upstream `v0.12` sources at
commit `85dcfe803fc2a21020ddcf15c3eb66b93d388add`, using the included miniz
implementation and with encryption support disabled.

- Source: <https://github.com/bfabiszewski/libmobi/tree/v0.12>
- License: LGPL-3.0-or-later (see `COPYING.libmobi`)
- Rebuild instructions: `native/libmobi/README.md` and
  `build/Build-LibMobi.ps1`

The complete corresponding source is available from the linked upstream tag.
